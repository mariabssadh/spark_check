# Web page (frontend)

Owner: Maria

A simple web page where a counsellor types in a student's 5 start-of-term survey scores and sees:
- The predicted end-of-term depression score (0 to 27)
- Whether the student is at risk (yes or no)

The page sends the scores to the model API (built by Yan-Ling) and shows a readable result. It is a screening aid, not a diagnosis.
